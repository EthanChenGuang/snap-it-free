# Quick Task: ngrok mobile access

Expose the local Next.js app (port 3001) via ngrok so it can be opened on a phone.

## Tasks

### Task 1: Start ngrok tunnel
- **action:** Run `ngrok http 3001` against the running production server
- **verify:** `curl -s http://127.0.0.1:4040/api/tunnels` returns a public HTTPS URL; tunnel returns HTTP 200
- **done:** Tunnel active and URL confirmed

### Task 2: Add npm script
- **files:** package.json
- **action:** Add `"tunnel": "ngrok http ${PORT:-3001}"` script
- **verify:** Script present in package.json
- **done:** Future tunnels can be started with `npm run tunnel`
