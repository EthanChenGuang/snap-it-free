# Phase 12.1: Category Names i18n (it/zh/en) - Context

**Gathered:** 2026-08-10
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 12.1 adds **trilingual display labels for the 17 Subito regalo category slugs** in the consumer app (it, zh, en). Canonical filter values remain the 17 slugs from `SUBITO_REGALO_CATALOG` (Phase 12 D-04) — only **human-readable labels** change with locale.

**In scope:**
- Static translation map in `messages/{it,en,zh}.ts` under `messages.feed.subitoCategories`
- Extend `getSubitoCategoryLabel` to resolve UI labels from messages for all locales
- Apply to all current UI consumers: FilterSheet, SubitoCategoryFilterChips, feed header category pills, list/map filter chips, and listing detail via `resolveListingCategory`
- I18N-01 key parity + typed slug coverage tests

**Out of scope:**
- PostForm 6 UGC PostCategory picker (unchanged per Phase 12 D-12)
- Admin/scraper console category labels
- DB schema changes; bulk backfill of `listing.category_en` / `listing_zh`
- FilterSheet layout, checkbox count, or merged category groups (Phase 12 D-14)
- Replacing PostForm with 17 Subito categories

**Depends on:** Phase 12 (canonical slug model + `getSubitoCategoryLabel` API)

</domain>

<decisions>
## Implementation Decisions

### Translation Source

- **D-01:** **Static messages map** — Add `messages.feed.subitoCategories` keyed by Subito slug in `messages/it.ts`, `messages/en.ts`, `messages/zh.ts`; single source of truth for UI category labels. — **Reversibility:** reversible.
- **D-02:** **Namespace** — Use `messages.feed.subitoCategories[slug]` (parallel to existing feed strings like `cityVenice`). — **Reversibility:** reversible.
- **D-03:** **API** — Extend `getSubitoCategoryLabel` to accept messages (or locale + messages lookup) and read static map before catalog fallback. — **Reversibility:** costly — all callers must pass messages or use a wrapper hook.
- **D-04:** **DB columns unchanged for UI** — `listing.category_en` / `category_zh` remain for scraped listing-specific translations; FilterSheet/chips/pills **do not** read DB columns. — **Reversibility:** reversible.
- **D-05:** **Key format** — Slug string as object key (e.g. `'informatica'`). — **Reversibility:** reversible.
- **D-06:** **Type safety** — `Record<SubitoRegaloSlug, string>` (or equivalent) so all 17 slugs are required at compile time. — **Reversibility:** reversible.
- **D-07:** **Catalog sync** — Unit test asserts `Object.keys(messages.feed.subitoCategories)` matches `SUBITO_REGALO_CATALOG` slugs exactly. — **Reversibility:** reversible.
- **D-08:** **I18N-01 key parity** — Run/enforce `messages/key-parity.test.ts`; all 17 slug keys present in zh, en, it. — **Reversibility:** reversible.
- **D-09:** **Italian strings** — Copy from `SUBITO_REGALO_CATALOG.labelIt` into `messages.it.ts`, fixing obvious typos (e.g. `Sports` → proper Italian `Sport`). — **Reversibility:** reversible.
- **D-10:** **English/Chinese strings** — Planner/executor drafts native-quality en/zh translations in message files; user may edit before ship. — **Reversibility:** reversible.

### UI Surfaces

- **D-11:** **All `getSubitoCategoryLabel` consumer surfaces** — FilterSheet, SubitoCategoryFilterChips (list + map), FeedHeaderRow active pills, and any other caller updated to pass messages/locale resolution. — **Reversibility:** reversible.
- **D-12:** **Listing detail** — `resolveListingCategory` uses static messages map when DB `category_en`/`category_zh` empty; DB columns still win when populated (preserve Phase 12 D-31 on scraped rows). — **Reversibility:** reversible.
- **D-13:** **PostForm unchanged** — Six UGC labels via `messages.post.categories` only (Phase 12 D-12). — **Reversibility:** reversible.
- **D-14:** **Admin/scraper out of scope** — Admin console keeps Italian catalog labels. — **Reversibility:** reversible.

### Italian Locale Behavior

- **D-15:** **Italian uses messages.it.ts** — Even for `locale === 'it'`, resolve via `messages.feed.subitoCategories`; catalog `labelIt` becomes reference/source, not runtime path for UI. — **Reversibility:** reversible.
- **D-16:** **Language switch** — Labels update instantly on locale change via existing `useMessages()` (no full page reload required). — **Reversibility:** reversible.
- **D-17:** **"All categories" chip** — Translate using existing feed strings (e.g. `messages.feed.cityAll` or equivalent "all categories" key); do not hardcode `Tutte` in `getSubitoCategoryLabel` for slug `'all'`. — **Reversibility:** reversible.

### Fallback Chain

- **D-18:** **Missing message key** — Runtime fallback to `SUBITO_REGALO_CATALOG.labelIt`; never show raw slug to users. — **Reversibility:** reversible.
- **D-19:** **UI vs detail resolution order:**
  - **UI surfaces (filters/chips/pills):** `messages.feed.subitoCategories[slug]` → catalog `labelIt`
  - **Listing detail (`resolveListingCategory`):** DB `category_en`/`category_zh` if populated → static messages map → catalog `labelIt`
  — **Reversibility:** reversible.
- **D-20:** **Unknown slug (not in catalog)** — Return `null` / hide label; do not map to catch-all. — **Reversibility:** reversible.
- **D-21:** **Missing keys in production** — No runtime throw; tests (`key-parity`, slug sync, `getSubitoCategoryLabel` tests) catch gaps in CI. — **Reversibility:** reversible.

### Claude's Discretion

- Exact signature for `getSubitoCategoryLabel` messages parameter (pass full `Messages` vs `messages.feed.subitoCategories` slice).
- Whether to add a thin `useSubitoCategoryLabel(slug)` hook wrapping `useMessages()` + `getSubitoCategoryLabel`.
- Specific en/zh translation wording for each of the 17 categories.
- Which existing feed key to reuse for the "all categories" chip vs adding `subitoCategoriesAll` if none fits.

</decisions>
