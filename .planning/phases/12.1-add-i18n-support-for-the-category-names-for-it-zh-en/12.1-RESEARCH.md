# Phase 12.1: Category Names i18n - Research

**Researched:** 2026-08-10
**Domain:** Trilingual UI labels for 17 Subito regalo category slugs (it/zh/en)
**Confidence:** HIGH

## Summary

Phase 12.1 is a **messages + lib resolver extension** with **no DB migration** and **no FilterSheet layout changes**. Phase 12 UAT confirmed FilterSheet shows Italian catalog labels regardless of app locale because `getSubitoCategoryLabel(slug, locale)` only uses `category_en`/`category_zh` from listing rows — filter UI callers never pass DB translations.

**Root cause:** `CATALOG_LABEL_BY_SLUG` in `lib/listings/subito-categories.ts` always returns Italian `labelIt` when locale is `it` or when en/zh DB columns are absent.

**Fix:** Add `messages.feed.subitoCategories: Record<SubitoRegaloSlug, string>` to `messages/{it,en,zh}.ts`; extend `getSubitoCategoryLabel` to accept `Messages` (or `feed.subitoCategories` slice) and resolve static map before catalog fallback. Update 4 UI call sites + `resolveListingCategory`.

**Primary recommendation:** Wave 0 TDD — add message maps + refactor resolver + tests; Wave 1 wire callers + update ROADMAP/I18N traceability + extend phase12 UAT script for locale checks.

## Recommended API Shape

```typescript
export function getSubitoCategoryLabel(
  slug: SubitoCategoryFilter,
  locale: AppLanguage,
  options?: {
    messages?: Messages;
    translations?: SubitoCategoryTranslationFields;
  },
): string | null;
```

**Resolution order (D-19):**

1. `slug === 'all'` → `options.messages.feed.cityAll` (fallback `'Tutte'`)
2. If `translations.category_en/zh` populated **and** caller is detail path → use DB column (preserve D-31)
3. `options.messages.feed.subitoCategories[slug]` if present
4. `CATALOG_LABEL_BY_SLUG.get(slug)` (safety fallback)
5. Unknown slug → `null` (not raw slug string)

For UI callers: pass `messages` from `useMessages()`; never pass listing translations.

For `resolveListingCategory`: pass `messages` + listing translations; DB wins when populated.

## Message Map Pattern

- **Type:** Import `SubitoRegaloSlug` from `@/lib/admin/subito-regalo-catalog`; use `satisfies Record<SubitoRegaloSlug, string>` in each locale file.
- **Italian:** Copy from catalog `labelIt`; fix `Sports` → `Sport` (D-09).
- **English/Chinese:** Draft consumer-friendly labels during execution (D-10).
- **Key parity:** Adding `feed.subitoCategories` object automatically covered by `messages/key-parity.test.ts` nested path walk (D-08).
- **Catalog sync:** Dedicated test: `Object.keys(messages.feed.subitoCategories).sort()` equals `SUBITO_CATEGORY_SLUGS.sort()` (D-07).
