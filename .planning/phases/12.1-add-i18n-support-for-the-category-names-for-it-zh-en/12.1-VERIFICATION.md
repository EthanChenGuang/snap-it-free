The one gap is not in the i18n feature itself but in its regression-guard artifact: `scripts/phase12-uat-automation.mjs`, which Plan 02 declared as a must-have and which `12.1-UAT.md`/`12.1-uat-results.json` cite as "5/5 passed" evidence, is now broken. The UAT script's DOM selector was never updated to match, so it now reports `checkboxes=0` and fails outright (exit 1) instead of confirming the feature.

This means Phase 12.1's own SUMMARY.md/UAT.md "passed" claims about browser-level verification are **stale as of current HEAD** — exactly the scenario this verifier is meant to catch. Fix is a one-line selector update in the script (target the chip-grid buttons instead of checkbox inputs), not new feature work.
