## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → `user_notification_prefs` | RLS restricts a session to its own row (`user_id = auth.uid()`) for select/insert/update |
| service_role → `delete_account_data` RPC | Only the server's service-role key may invoke it; execute is revoked from `anon`/`authenticated` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-14-01 | Elevation of Privilege | `delete_account_data` RPC | high | mitigate | `execute` revoked from `public`/`anon`/`authenticated`, granted only to `service_role` — a logged-in user cannot call `.rpc('delete_account_data', { target_user_id: <someone else> })` directly from the browser; only the server's service-role client can invoke it |
| T-14-02 | Tampering | `user_notification_prefs` RLS | medium | mitigate | Three policies scoped to `user_id = auth.uid()`, mirroring the already-proven `profiles` table pattern (017_user_locale.sql) |
| T-14-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages this plan |
