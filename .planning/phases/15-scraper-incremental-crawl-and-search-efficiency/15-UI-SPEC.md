## Spacing Scale

Stitch 4px grid (project tokens — same as scraper-dashboard HTML):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| `space-xs` | 4px | Chip/dot gaps; icon-to-label gaps inside status chips |
| `space-sm` | 8px | Gap between stacked field label and helper; gap between Full crawl primary button and adjacent controls |
| `space-md` | 16px | Default field stack spacing inside cards; metric card internal gaps |
| `space-lg` | 24px | Card padding (`p-space-lg` / match existing `p-5`≈20px by migrating **new** cards to `p-space-lg` or keep `p-5` for visual parity with sibling Settings cards — **prefer matching adjacent SettingsClient cards** so new sections don’t jump density) |
| `space-xl` | 48px | Page header bottom margin rhythm / major section breaks (`mb-space-xl` on page title block per Stitch settings) |

Exceptions:
- Touch targets: Full crawl button, Save/Update, and numeric inputs use `min-h-11` (44px) where interactive — accessibility floor, not a spacing-grid violation.
- Existing Settings cards use `p-5` / `space-y-6` — new Phase 15 cards **match that density** (port, don’t redesign). Do not introduce `rounded-xl`/`shadow` drift even though Stitch HTML uses `rounded-xl` in places; React admin already uses `rounded` + `border-outline-variant` — **follow live React admin**, which is the production port of Stitch.

## Typography

Admin surfaces already use Inter Stitch roles. Declared for Phase 15 net-new copy only (exactly 4 roles, 2 weights):

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Body | 15px (`body-md`) | 400 | 1.6 | Helper text under crawl fields; degraded banner body; proxy last-block reason value |
| Label | 12px (`label-sm`) | **600** via `font-semibold` | 1.2 | Status chips (Configured / Not configured / Degraded / Incremental / Full); uppercase metadata keys; pause-style status text |
| Label (form / button) | 14px (`label-md`) | **600** via `font-semibold` (matches existing Settings labels/buttons) | 1.4 | Field labels (`Early-stop K`, etc.); Full crawl + Save button labels |
| Heading | 15px section / 30px page | **600** | 1.3 | Section card titles (`Crawl efficiency`, enhanced `Proxy`); page title unchanged |

**Weight contract:** exactly **2 weights** — **400** (body/helpers) and **600** (chips, metadata keys, section titles, form labels, buttons). Always apply `font-semibold` on `label-sm` / `label-md` so rendered weight is 600 (never rely on bare token defaults). Do not introduce 700 on these surfaces (page title already 600 at 30px in SettingsClient).

## Color

Monochrome-first (DESIGN.md). 60/30/10:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f9f9f8` (`surface` / `background`) | Admin page canvas |
| Secondary (30%) | `#ffffff` / surface cards with `border-outline-variant` `#e5e5e5` (project border); chip fill `#f1f1f0` / `surface-container` / `surface-container-high` | Settings cards, metric tiles, status chips |
| Accent (10%) | `#000000` (`primary`) | **Reserved exclusively for:** primary Save/Update CTA fill; Full crawl **primary** treatment when it is the intentional run trigger on that card; configured status **dot** when proxy is set; checked toggles; active anti-block card ring (existing) |
| Destructive | `#ba1a1a` (`error`) / `error-container` `#ffdad6` | **Reserved exclusively for:** save/API error inline text; failed run status chip (existing). **Not** for soft degraded banner |

Accent reserved for: Save/Update primary button, Full crawl primary button, proxy “Configured” dot (filled black), Global Pause checked track (existing). Never paint the degraded soft banner with primary black fill or error red.

**Soft degraded banner (extension from DESIGN.md + existing `capExceededNotice` pattern):**
- Container: `border border-outline-variant bg-surface-container-low` (same family as translation-cap notice in `SettingsClient`)
- Icon: Material Symbol `warning` at secondary (`text-secondary`), not `error`
- Text: `text-on-surface` body-md — calm, informational
- Do **not** use `bg-error-container` — D-15-18 is a soft gate, not a hard failure

**Proxy “Not configured” chip:** hollow/muted dot `bg-outline-variant` (existing SettingsClient pattern) — keep.

## Copywriting Contract

Admin UI copy lives in `components/admin/admin-messages.ts` (Chinese-first, matching existing settingsMessages). EN below is the semantic contract; implement zh strings in the same file tone (short, declarative, no trailing punctuation on labels).

| Element | Copy |
|---------|------|
| Primary CTA (crawl card) | **"Run full crawl"** — zh: `立即全量抓取` — triggers one full-refresh run (disables early-stop for that run; D-15-08) |
| Primary CTA (settings footer, existing) | **"Update configuration"** — zh: keep `settingsMessages.updateConfiguration` (`更新配置`) — saves crawl fields + proxy/alerts |
| Empty state — last block reason | **"No recent block"** — zh: `暂无封禁记录` — when proxy health has no stored last-block reason |
| Empty state — degraded count | Show **`0`** (numeric), not a prose empty state |
| Error state — config save | Reuse **"Save failed. Check fields and try again, or refresh."** — existing `settingsMessages.saveError` |
| Error state — full crawl enqueue fails | **"Could not start full crawl — try again"** — zh: `无法启动全量抓取，请重试` |
| Destructive confirmation | **None** — Full crawl is an operator run trigger, not a destructive data wipe. No two-step confirm. Disable the button while a job is already queued/running (reuse SourceCard “Run now” busy pattern if one exists; otherwise disable + label `Starting…` / `启动中…`) |

**Field labels & helpers (Crawl efficiency card — D-15-32):**

| Field | Label | Helper | Default shown |
|-------|-------|--------|---------------|
| `early_stop_k` | Early-stop K | Consecutive known-unchanged listings before stopping per category URL | `5` |
| `full_refresh_hours` | Full refresh (hours) | Interval before the next automatic full crawl (early-stop off for one run) | `24` |
| `max_pages` | Max pages per URL | Cap for pagination on full-refresh runs only; incremental stays page 1 | `3` |
| Full crawl button | Run full crawl | Starts one full-refresh run now | — |

**Proxy health rows (D-15-21 — extend existing Proxy card):**

| Row | Label | Value states |
|-----|-------|--------------|
| Status chip | (existing) Configured / Not configured | keep `proxyConfigured` / `proxyNotConfigured` |
| Last block reason | Last block reason | string from worker, or empty-state copy above |
| Degraded run count | Degraded runs | integer count of recent/total degraded runs (planner picks window; UI shows the number + optional “recent” helper) |

**Degraded banner (D-15-18):**

| Element | Copy |
|---------|------|
| Heading | **"Running degraded"** — zh: `降级运行中` |
| Body | **"Proxy is not configured. Full-matrix production crawls may be blocked; runs are marked degraded."** — zh: `未配置代理。全量生产抓取可能被封；相关运行已标记为降级。` |
| Optional link | **"Open proxy settings"** → `/admin/settings` (Dashboard only) |

**Run detail chips/metrics (SCRP-E07 — extension):**

| Element | Copy |
|---------|------|
| Crawl mode chip | `Incremental` / `Full` — zh: `增量` / `全量` |
| Degraded chip | `Degraded` — zh: `降级` — show only when `degraded === true` |
| Metric: crawl skips | `Crawl skipped` — zh: `抓取层跳过` |
| Metric: HTTP requests | `HTTP requests` — zh: `HTTP 请求数` |
| Metric: wall time | `Wall time` — zh: `墙钟时间` (format seconds as `Xm Ys` or `Ns`) |

**Validation gate label update (D-15-26 — if chips remain on Settings/Source):** rename selector-rate chip concept to **JSON field completeness** when the gate ships — zh label e.g. `JSON 完整度`. Exact threshold % is ADR/planner numeric discretion — UI only swaps the label string.

## Interaction Notes (prescriptive)

1. **Full crawl:** POST job with full-refresh flag (or dedicated endpoint — planner). Button is primary black on the Crawl efficiency card. On success: toast/inline success optional; prefer `router.refresh()` + disable until idle. No confirm dialog.
2. **Numeric fields:** `type="number"` with monospace like daily-cap input; min constraints: K≥1, hours≥1, max_pages≥1 (and ≤ sensible max e.g. 10 — planner). Save via existing sticky Update configuration footer (fields included in same PATCH) **or** card-local save — **lock: same sticky footer PATCH as other settings** to avoid two save affordances.
3. **Anti-block:** unchanged interaction on Source Detail; fallback Playwright queue inherits preset (backend) — no Settings duplicate selector.
4. **Degraded banner:** dismissible? **No** — stays while condition holds (operator must configure proxy). Link to settings from Dashboard only.
5. **Borders:** `border-outline-variant` / notion thin border; **no card drop shadows**.
6. **Radius:** match existing admin `rounded` (not new `rounded-2xl`).
