## Spacing Scale

From `phase08/structured_minimalist/DESIGN.md` and `app/globals.css` — multiples of 4 only:

| Token | Value | Usage |
|-------|-------|-------|
| space-xs | 4px | Checkbox gaps, chip inline padding |
| space-sm | 8px | Chip row gaps, compact inline spacing |
| space-md | 16px | Matrix panel padding, card padding, button px |
| space-lg | 24px | Section gaps, form subsection padding, grid gutter |
| space-xl | 48px | Page section breaks (`mb-space-xl`) |
| gutter | 24px | Page horizontal padding (`px-gutter`, `p-gutter`) |
| container-max | 1200px | Admin main max width |

Exceptions:

- Map floating search / category panel: `max-w-2xl` (672px) centered — per consumer map prototype
- Map drawer horizontal cards: `w-80 md:w-96` card width — per prototype snap carousel
- Icon-only admin header buttons: `w-10 h-10` (40px) touch target
- **Stitch-faithful exceptions (documented in phase08 prototypes — not generic glassmorphism):**
  - Consumer category filter panel: `rounded-xl`, `bg-surface/80 backdrop-blur-md` — `consumer_map_category_filters/code.html` line 161
  - Map search bar: `rounded-full`, subtle `backdrop-blur-sm bg-opacity-90` — same prototype
  - Modal overlay: `backdrop-blur-sm` on `#1a1c1c/40` — `source_detail_confirm_seed_overwrite/code.html`
  - Map drawer article cards: `rounded-xl` — consumer map prototype (structural border, no drop shadow)
- **Badge vertical padding:** Stitch HTML uses `py-0.5` on category badges; **implementation ports as `py-1` (4px)** to satisfy spacing grid while preserving visual density

## Typography

**Contract cap:** 4 sizes × 2 weights (400 / 600). Map prototype HTML aliases map into this contract.

| Role | Size | Weight | Line height | Prototype alias | Usage |
|------|------|--------|-------------|-----------------|-------|
| Display | 40px | 600 | 1.2 | `font-headline-lg`, `font-h1` | Admin page title "Subito Configuration" |
| Heading | 24px | 600 | 1.4 | `font-headline-sm`, `font-h3` | Matrix section title, card titles |
| Body | 15px | 400 | 1.6 | `font-body-md` | Descriptions, modal body, listing excerpt |
| Label | 14px | 400 / 600 | 1.4 | `font-label-md` | Buttons, nav, matrix labels, chip text |

**De-emphasis:** Prototype `label-sm` (12px) → render at **label 14px** with `text-secondary` or `text-on-surface-variant` and `letter-spacing: 0.01em` where prototype uses 12px (URL count line, zone uppercase labels, "Categoria" row label).

**Monospace:** Target URLs textarea — `font-mono text-sm` (14px mono stack); not a 5th size token.

**Locale:**

- Admin chrome: **Chinese** (Phase 6 D-34 continuity)
- Matrix category checkbox labels: **Italian** (D-08) — exact strings below
- Consumer category chips + badges: **Italian** default; i18n via `category_en` / `category_zh` when locale ≠ it (D-31)
- Technical URL template string: English path segments as shown in prototype

### Interaction states — Screen 1

| State | Trigger | UI behavior |
|-------|---------|-------------|
| **Default load** | Page mount | Venezia + Padova checked; all 17 categories checked; preview shows `34 URLs selected`; warning banner visible (34 ≥ 30); textarea shows persisted `target_urls` from DB |
| **Matrix toggle** | Any city/category checkbox change | Recompute `selectedCount = \|cities\| × \|categories\|`; update preview line; show/hide warning when crossing 30 threshold |
| **Select all / Clear** | Link click | Check/uncheck all 17 category boxes; do not affect city boxes |
| **Generate URLs** | Click "生成 URL" | Build URLs for checked city × category pairs; **dedupe** (D-06); **replace** textarea content with generated set merged with any manual non-empty lines user had (generated lines first, then unique manual lines not in generated set — D-05) |
| **Apply recommended seed (empty textarea)** | Click when textarea blank/whitespace | Fill textarea with full 34-URL preset (17 × 2 cities); sync matrix checkboxes to all checked; no modal |
| **Apply recommended seed (overwrite)** | Click when textarea has ≥1 URL | Open Screen 2 confirm modal (D-14); do not mutate textarea until confirm |
| **Warning banner** | `selectedCount >= 30` | Non-blocking inline banner: `bg-[#f1f1f0] text-amber-700`, `warning` icon, copy above; remains visible while count ≥ 30 |
| **Save** | Sticky footer | Dedupe all non-empty lines before PATCH (D-06); existing validation extended for Padova paths (D-03) |
